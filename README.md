# 숏드라마 작가실 (shortdrama-writers-room)

처음 해 보는 사람도 몇 번 고르기만 하면 세로 숏드라마 대본이 완성되는 Claude 스킬입니다.
완성된 대본은 [Higgsfield Short Drama](https://higgsfield.ai/short-drama)에 올리거나, 같은 대화에서 Higgsfield MCP의 `/short-drama`로 바로 영상으로 만들 수 있습니다.

Claude가 메인 작가를 맡고, 사용자는 제작자로서 고르고 승인만 합니다.
질문은 한 번에 하나씩 나오고, 번호가 붙은 선택지 가운데 하나에 추천 표시가 붙어 있습니다.
번호만 답하면 되고, 어느 질문에서든 "알아서"라고 답해도 됩니다.

## 할 수 있는 일

- 아이디어가 없어도 이야기 후보 세 개를 만들어 줍니다.
- 한 줄 아이디어를 짧은 회차에 맞는 이야기로 다듬습니다.
- 이미 써 둔 대본을 사이트 형식에 맞게 옮깁니다. 이때 줄거리와 대사는 건드리지 않습니다.
- 3화, 6화, 10화 회차 구성이나 1화로 끝나는 단편을 짭니다.
- 회차 대본을 쓰고, 이어서 다음 화를 씁니다.
- 질문 없이 여러 편을 한꺼번에 쓰는 자동화 요청도 받습니다.

## 설치

설치에 필요한 파일은 `SKILL.md` 하나뿐입니다.

**Claude 앱(claude.ai)**
1. `shortdrama-writers-room` 폴더를 zip으로 묶습니다. 이미 묶인 `shortdrama-writers-room.zip`이 있으면 그 파일을 쓰면 됩니다.
2. Claude 설정의 Skills 메뉴에서 zip 파일을 올립니다.
3. 스킬을 쓰려면 설정에서 코드 실행·파일 생성 기능이 켜져 있어야 합니다.

**Claude Code**
```
~/.claude/skills/shortdrama-writers-room/SKILL.md
```
위 경로에 `SKILL.md`를 넣으면 됩니다. 프로젝트에서만 쓰려면 `.claude/skills/` 아래에 넣습니다.

## 사용법

### 시작하기

```
숏드라마 작가실 스킬로 숏드라마 만들고 싶어.
```

첫 질문은 어디서부터 시작할지입니다.

```
1. 아무것도 없어요. 이야기부터 같이 만들어요
2. 한 줄 아이디어가 있어요
3. 써 둔 대본이 있어요
4. 질문 없이 알아서 1화까지 써 주세요
```

### 1번(이야기부터 같이)을 고르면 이어지는 질문

| 순서 | 질문 | 추천 답 |
|---|---|---|
| 1 | 사이트에서 쓸 스타일 | K-Drama |
| 2 | 보는 사람이 느꼈으면 하는 기분(통쾌함, 설렘, 조마조마, 소름) | 통쾌함 |
| 3 | 이야기 후보 세 개 중 고르기(섞기, 다른 걸로도 가능) | 추천 표시된 후보 |
| 4 | 회차 수와 한 화 길이 | 3화, 한 화 1분 |
| 5 | 회차 구성 확인 | "좋아요" 또는 고칠 점 |

다섯 번째 답을 하면 1화 대본이 나옵니다. 따로 말하지 않으면 배경은 한국, 대사는 한국어로 씁니다.

### 질문 없이 한 번에

설정을 처음부터 다 적으면 질문 없이 바로 씁니다.

```
숏드라마 작가실 스킬로, 질문 없이 알아서 써 줘. 대사는 한국어, K-Drama, 한 편 1분, 서로 다른 이야기 세 편의 1화.
```

### 고치기와 다음 화

- 고칠 곳은 "세라 대사를 더 차갑게"처럼 말로 알려 주면 됩니다.
- 다음 화는 "2화", "다음", "계속" 가운데 아무 말로나 요청하면 됩니다. 새 화는 앞 화가 끊긴 바로 그 순간에서 시작하고, 인물의 생김새와 옷은 그대로 이어집니다.

## 받는 결과

대본은 서식 없는 텍스트 한 덩어리로 나옵니다. 그대로 복사해 붙이거나 TXT 파일로 올리면 됩니다. 파일을 만들 수 있는 환경에서는 `제목_1화_대본_v1.txt` 파일로도 저장합니다.

```
제목
1화
세로 9:16 · 약 60초 · K-Drama · 서울 · 대사 한국어
첫 화면: (첫 장면의 사건). 건물 전경이나 바깥 풍경 없이 바로 이 장면으로 시작한다.

등장인물
이름, 나이. 처지. 생김새와 옷.

장면 1. 장소. 밤.

동작.

이름: 대사
```

대본 아래에는 다음 세 가지가 붙습니다.
- 점검 한 줄. 예: "대사 142음절 · 15줄 · 예상 약 61초"
- 2~3문장 줄거리
- 다음 단계 안내

## 영상으로 만들기

**사이트에서:** [higgsfield.ai/short-drama](https://higgsfield.ai/short-drama)에 대본 파일을 올리고, 대본을 쓸 때 고른 스타일을 선택합니다.

**같은 대화에서:** Higgsfield MCP를 Claude에 연결해 두었다면 이렇게 씁니다.

```
Higgsfield로 /short-drama 실행해서 위 대본으로 만들어 줘.
```

생성에는 크레딧이 듭니다. 스킬은 화질과 예상 비용을 먼저 보여 주고, 승인을 받은 뒤에 시작하도록 되어 있습니다.

## 대본을 쓰는 기준

| 기준 | 내용 |
|---|---|
| 첫 3초 | 말이 없어도 보이는 사건으로 연다. 누가 누구에게 당하는지, 지켜보는 사람이 누군지 보인다 |
| 걸린 것 | 열쇠, 봉투, 금액처럼 손에 잡히는 것. 마감은 "열 시까지"처럼 시각으로 말한다 |
| 흐름 | 사건은 앞 사건 때문에 일어난다. 회상과 과거 설명은 쓰지 않는다 |
| 반전 | 앞에서 한 번 보인 물건이나 말로 일어나고, 힘이 누구에게 있는지를 바꾼다 |
| 끝 | 사건 직후, 대답 직전에 끊는다 |
| 사이트용 | 카메라에 보이는 것만 쓴다. 읽어야 하는 글자, 내레이션, 카메라 용어는 넣지 않는다. 모든 인물에 나이와 옷차림을 적는다 |
| 분량 | 한국어 대사는 음절로 센다. 1분 회차는 대사 120~160음절이다 |
| 안전 | 가상 인물만 쓴다. 실존 인물, 다른 작품의 캐릭터, 상표는 넣지 않는다 |

자세한 기준은 `SKILL.md`에 있습니다.

## 참고

- 이 스킬은 숏드라마 대본을 만드는 비슷한 역할의 다른 스킬과 별개로, 처음부터 새로 쓴 것입니다.
- 비슷한 숏드라마 스킬을 같이 설치하면 "숏드라마 스킬"이라고만 했을 때 어느 쪽이 실행될지 알 수 없습니다. "작가실 스킬로"처럼 이름을 붙여 부르세요.
- 분량 계산에 쓰는 "1초에 4.5음절"은 연기하는 대사를 기준으로 잡은 추정치입니다. 사이트가 실제로 만드는 영상은 대본에서 계산한 길이보다 길게 나올 수 있습니다.
- 사이트 스타일 목록(15종)은 2026년 11월 기준입니다. 목록에 없는 스타일 이름을 말해도 받습니다.
